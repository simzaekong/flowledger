# 흐름 가계부

iOS 16.4 이상을 대상으로 한 오프라인 가계부입니다. 앱을 처음 열면 빈 화면에서 시작합니다.
수입과 지출을 이름·금액·카테고리와 함께 입력하면 생키 그래프가 바로 업데이트됩니다.
그래프 왼쪽에는 수입 카테고리, 오른쪽에는 지출 카테고리와 남은 금액이 나옵니다.
가지나 금액 요약을 탭하면 상세 내역이 열립니다. iPhone에서는 기본 시트와 목록으로 열리며, 항목을 탭해 수정하거나 왼쪽으로 밀어 삭제할 수 있습니다. 수정 화면 아래에도 기록 삭제 버튼이 있습니다. 해당 화면에서 이름·금액·카테고리·날짜를 수정할 수 있습니다.
상단 검색 버튼에서 전체 기간의 지출을 이름이나 카테고리로 검색할 수 있습니다.
수입과 지출 모두 주식 카테고리를 제공합니다. 남은 금액은 선택한 기간의 수입 합계에서
지출 합계를 뺀 값이며, 지출이 더 크면 그래프에 부족분이 나타납니다.

평소에는 기록 날짜가 오늘로 설정됩니다. 지난 월이나 연도를 보고 있으면 그 기간의 첫날로
설정됩니다. 하단 날짜 버튼을 누르면 작은 시트에서 날짜 휠이 바로 열립니다. 이름을 입력하면 같은 유형의 기록에서 최대 세 개의 이름을 추천합니다.
기록은 기기에 저장됩니다. 인터페이스는 시스템 라이트·다크 모드를 따릅니다.
기간 전환, 입력창, 날짜 선택기와 메뉴는 UIKit을 사용합니다. iOS 26에서는 상단 금액 요약, 하단 패널과 버튼에 Liquid Glass가 적용됩니다.
빠른 추가 패널의 손잡이를 탭하거나 위아래로 밀어서 접고 펼칠 수 있습니다.

## 설치

FlowLedger.ipa를 아이폰의 파일 앱에 저장하고 SideStore의 My Apps 화면에서 + 버튼으로
선택하세요. SideStore가 현재 기기에 맞게 서명합니다. 배포 패키지에는 Apple 개발자 서명과
프로비저닝 프로파일이 포함되어 있지 않습니다.

## 다시 빌드하기

- macOS 및 Xcode에서 저장소 루트의 `./build-ipa.sh`를 실행합니다.
  결과는 `dist/FlowLedger.ipa`입니다.
- GitHub에서 빌드하려면 소스 ZIP의 내용을 저장소 루트에 올린 뒤
  Actions의 **Build iPhone IPA and previews** 워크플로를 실행합니다. `main`에 앱 또는 빌드 코드가
  반영되면 자동으로 실행됩니다. 완료된 실행의 **Artifacts**에서 `FlowLedger-IPA`와
  `FlowLedger-iPhone-screenshots`를 받을 수 있습니다. 화면 캡처에는 임시 iPhone 시뮬레이터의
  샘플 거래만 사용합니다. 별도로 캡처하려면 macOS에서 `./Build/capture-simulator.sh`를 실행합니다.
- Linux에서는 clang 19, ld64.lld 19, Python 3, zip으로 교차 빌드할 수 있습니다.
  필요하면 `CLANG`과 `LD64`에 바이너리의 경로를 지정하세요.

## JSON 거래 가져오기

상단의 다운로드 모양 버튼에서 파일 앱의 UTF-8 `.json` 파일을 선택하세요.
[예시 파일](Examples/transactions.json)처럼 거래 배열을 넣거나, 객체의 `transactions` 키에
배열을 넣을 수 있습니다. 한 번에 최대 5 MB를 읽습니다.

| 필드 | 형식 |
| --- | --- |
| `date` | `YYYY-MM-DD` |
| `kind` | `income` / `expense` 또는 `수입` / `지출` |
| `name` | 1~80자의 거래 이름 |
| `amount` | 1 이상의 정수 원화 금액. `"8,500"` 같은 숫자 문자열도 가능 |
| `category` | 앱에 표시되는 카테고리 이름 또는 앱 내부 ID |
| `id` | 선택 사항. 원본 거래의 고유 ID를 그대로 사용하면 재가져오기 때 중복을 막을 수 있습니다 |

같은 ID가 이미 있으면 기존 기록을 보존합니다. ID를 생략하면 유형·날짜·카테고리·이름·금액이
같은 거래의 기존 개수만큼 건너뜁니다. 잘못된 행이 있으면 해당 행 번호를 표시하고 전체 가져오기를
중단합니다. 은행이나 카드사 파일은 먼저 예시 형식에 맞춰 변환해야 합니다.
